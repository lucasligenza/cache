Privacy policy

Draft dated 10 October 2026. This describes the CacheNotes website as it works today. It is not a finished policy.

What the app is

CacheNotes (“cache”) is a note organizer. You write notes, file them in directories, and can ask the app to remind you. The same account is stored in one Supabase project, so a note saved on the website can show up on another signed-in device.

What we store

  • Account. An email address and a password hash, held by Supabase Auth, or an anonymous guest id if you choose “continue as guest”. We never see your password. A guest is still a real account on the server.
  • Notes. The text, which directory it is in, color, pin, review flag, reminder time, trash time, and timestamps.
  • Directories. The name and color.
  • Reminders. If you turn notifications on, we store a web-push subscription for that browser: an endpoint URL and two keys. A due reminder sends the first 100 characters of the note.
  • This browser. Notes that have not synced yet sit in local storage (cn_outbox_v1). Theme, accent color, the first-run flag, and a guest “create an account” nudge are stored there too. The login session is stored by the Supabase client. None of that is sent anywhere except to your own account when a note syncs.

Who handles it

  • Supabase (on Amazon Web Services) holds the database and the login. Row-level security limits each account to its own notes, directories, and push subscriptions. Reminder sends run as a Supabase edge function, which reads due notes and the matching push subscription.
  • Vercel hosts the website. Serving a page produces ordinary host logs: IP address, browser, and the URL requested. Note text is not in those page requests.
  • Web push. The reminder is delivered by your browser’s push service — Google, Apple, or Mozilla, depending on the browser. That service sees the notification payload (title plus up to 100 characters of the note) and the subscription endpoint.
  • Google Fonts. The app loads JetBrains Mono from fonts.googleapis.com and fonts.gstatic.com. Google receives your IP address when the font file is downloaded. These legal pages do not load that font.
  • Error reports, only if configured. Crashes can be posted to a collector URL (VITE_ERROR_REPORT_URL). That collector may be Sentry or something else. A report contains the error message, stack trace, page URL, browser type, a release id, and the time. It does not include your notes or your email. If the URL is unset, nothing is sent.

The iOS app

The iOS app uses the same Supabase account and database. It can also send a note’s text to Anthropic to suggest a directory, and only when that build has an API key and you trigger the sort. The website does not do this. Confirm that sentence before publishing if the iOS build changes.

How long

Notes stay until you delete them, empty the trash, or delete the account. Deleting the account removes your notes, directories, and push subscriptions on the server, then deletes the login. This browser’s unsynced queue for that account is cleared as part of the same action. Another device can still have a leftover queue until it is opened and signed out.

Guest logout ends the session in this browser. The server copy of a guest account remains until you delete the account.

Your choices

  • Export JSON or Markdown from Settings → data, before you delete anything you might want.
  • Turn notifications off in Settings. That drops this browser’s push subscription.
  • Delete the account in Settings. Type delete to confirm. It is permanent.
